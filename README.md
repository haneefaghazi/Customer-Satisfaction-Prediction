# 😊 Customer Satisfaction Prediction

This project uses machine learning to predict customer satisfaction based on service and behavioral data. By analyzing trends and key factors, the model helps businesses better understand what drives customer happiness and loyalty.

## 📊 Project Overview

Customer satisfaction is critical for customer retention and business growth. This project builds a predictive model using classification techniques to determine whether a customer is likely to be satisfied or dissatisfied.

## 🧰 Tools & Technologies

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Scikit-learn
- XGBoost / Random Forest
- Jupyter Notebook

## 🔄 Workflow

### 1. Data Exploration & Cleaning
- Checked for missing values, outliers, and data types
- Visualized distributions and correlation between features

### 2. Feature Engineering
- Created meaningful variables
- Handled categorical and numerical features
- Feature scaling and encoding

### 3. Model Building
- Trained and evaluated multiple classification models:
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - XGBoost
- Used GridSearchCV for hyperparameter tuning

### 4. Evaluation
- Used accuracy, precision, recall, F1-score, and confusion matrix
- Visualized results using ROC curves and feature importance plots

- Achieved high performance with [Your Best Model] (e.g., XGBoost)
- Identified top drivers of satisfaction such as response time, issue resolution, and service quality
- Generated actionable insights for improving customer experience

## 🧠 Insights

- Fast and efficient service is the top driver of satisfaction.
- Dissatisfaction often stems from unresolved or delayed issues.
- Predictive models can help flag unhappy customers before they churn.
